HERRAMIENTAS MCP DISPONIBLES PARA CONSULTAS DE DATOS:
  - execute_sql(query, params=None)
      Ejecuta una consulta SQL de LECTURA (SELECT / SHOW / WITH).
      BLOQUEA INSERT/UPDATE/DELETE/DROP/ALTER/CREATE/TRUNCATE.
      Devuelve columnas + filas en formato JSON.
      Ejemplos:
        execute_sql(query="SELECT * FROM reservations ORDER BY created_at DESC LIMIT 50")
        execute_sql(query="SELECT r.*, c.doc_identidad, c.nombre_completo
                          FROM reservations r JOIN clients c ON r.client_id = c.id
                          WHERE c.doc_identidad = $1", params=["12345678"])
  - get_db_schema()
      Devuelve tablas, columnas, tipos y relaciones. USAR SIEMPRE antes de
      armar cualquier consulta para confirmar nombres y tipos.
  - get_current_datetime(format="pretty")
      Fecha y hora actual en Peru (UTC-5). USA CADA VEZ que necesites
      calcular fechas, duraciones o estados por vencimiento.
  - get_current_date()
      Fecha actual (YYYY-MM-DD) en Peru.
  - get_day_of_week()
      Nombre del dia de la semana actual en espanol.

CONVENCIONES DE DATOS CRITICAS:
  - Fechas: formato YYYY-MM-DD en SQL; 19/05/2026 solo para pantalla.
  - IDs de catalogos son numericos; para filtrar usa el codigo del catalogo:
      estado_reserva.codigo = 'PENDIENTE', estado_reserva.codigo = 'CONFIRMADA', etc.
    Categorias conocidas:
      tipo_documento.codigo: DNI | CE | PASSPORT | DNI_EXT
      tipo_habitacion.codigo: SIMPLE | DOBLE | TWIN | SUITE | FAMILIAR
      estado_habitacion.codigo: DISPONIBLE | OCUPADA | MANTENIMIENTO | LIMPIEZA
      estado_reserva.codigo: PENDIENTE | CONFIRMADA | CHECK_IN | CHECK_OUT | CANCELADA | NO_SHOW
  - Telefonos: sin espacios ni guiones, siempre con codigo de pais (+51 para Peru).
  - Documento de identidad: clients.doc_identidad, tipo en clients.id_tipo_documento.
